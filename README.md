# Julia Portfolio

Personal portfolio website built with React to present my profile, skills, projects and resume.

This project is a portfolio designed to showcase my background, my technical work, and my professional journey in a modern and engaging format. It includes multiple sections for introduction, skills, project presentation, curriculum, and contact.

## Overview

This portfolio was created to:
- present my profile and professional identity
- highlight my skills and strengths
- showcase selected projects with details
- offer a modern, responsive user experience

## Tech Stack

- React 18
- React Router DOM
- Sass
- EmailJS
- GitHub Pages deployment via `gh-pages`

## Features

- Responsive portfolio layout
- Multi-page navigation with React Router
- Project gallery and individual project detail pages
- Skills section with structured content
- Curriculum section
- Contact form
- Data-driven content loaded from JSON files
- GitHub Pages ready deployment setup
